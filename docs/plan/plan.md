## 生成物のバージョン管理（レポート・チャプター）

- [ ] **レポートの世代保持**（2026-09-10 メモ）: 現状は再生成で `_report/` を無条件に上書き
      （md / html / json を置き換え、`images/` は全削除してから再保存）。手直しした md が消える。
      案: 再生成前に前回分を `_report/history/YYYYMMDD-HHMM/` へ退避（md・json・images）、
      プレビューのツールバーに世代の切り替え／復元、上限 N 世代で古いものから削除。
      中止時の不整合（画像だけ新しい）も退避があれば復元で直せる
- [ ] **チャプターの世代保持**: 再分析で data.json の toc が置き換わる（ブックマークは保持される）。
      手で編集したチャプターを守るため、分析前に `toc` を `toc_history[]`（日時・source 付き）へ
      退避し、チャプタータブから戻せるようにする。まずは「直前の 1 世代に戻す」から
- [ ] 共通: 退避は容量を食うので画像は世代ごとに持たず、章とキャプション（json）だけ保持して
      画像は必要時に再抽出する方式も検討
