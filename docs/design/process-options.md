# 処理ごとのオプション

最終更新: 2026-09-12

操作エリアに「処理名・設定要約・実行」を並べる。設定要約を押すとその行の下にオプションを展開し、他の行を閉じる。設定変更だけでは処理を開始しない。補正は専用オプションがなく、共通 LLM を使用する。

- 文字起こし: エンジンとインストール済み Whisper モデル。既存の runtime API で保存し、失敗時は元の選択に戻して行内にエラーを表示する。未取得モデルのインストールはランタイム設定へ移動して行う。
- 字幕生成: 高品質 / 高速。
- 動画分析: 動画の種類、解析モード、サンプリング、最大フレーム数、出力言語。
- レポート: LLM 使用、章立て再構成、形式、章あたりの画像上限。LLM がオフのときは章立て再構成・形式を無効にする。

選択値は既存の settings.json / ui-settings のキーをそのまま使い、次回起動時に復元する。分析・チャット・レポートが共有する値があるため、SSE 処理中は全行の設定を固定する。文字起こし設定の保存中は文字起こしの実行も無効にする。

全体設定には字幕表示、プレイヤー、プロンプト、ランタイム、情報を残す。ランタイムの Whisper 操作はインストール用とし、使用モデル・エンジンは文字起こし行に集約する。

幅420px以下では設定要約を2段目へ移動する。既存の btn-ghost・色トークン・Lucide を使用し、aria-expanded / aria-controls / fieldset のラベルで開閉と設定対象を伝える。

## 検証

モック API を使った Electron 確認: 5行の描画、ID重複なし、保存値復元、要約更新、変更API送信、排他的な開閉、実行中ロックと解除、インストール済み候補限定、エンジン変更、失敗時の復元、380px幅の横溢れなし。画面キャプチャでもレイアウトを確認。実モデルによる推論は未実施。

## 動画・字幕ファイルの操作

動画はファイル一覧またはドラッグ＆ドロップで開く。操作エリアに動画読込ボタンを置かない。原文・日本語SRTの読込／解除はプレイヤーの「字幕」メニューに配置し、表示のON/OFFと区別したラベルにする。読込／解除時はメニューを閉じる。解除は現在の字幕を外すだけで、SRTファイルは削除しない。
